如何手动安装/更新渲染器

游戏自动安装渲染器失败。这可能是权限设置或者其他特殊情况导致的。

在通常情况下，游戏会自动检查并安装渲染器。不过不用担心，根据以下步骤可以手动安装渲染器并打开你的地图。

  1. 在资源管理器中打开这个文件夹中的压缩包：
    打开没有看到文件夹位置？

    找到并打开 CSLModernMapRenderer.zip。点击“打开”后，浏览器或 Windows 可能先询问是否继续，可查看下面的说明。

    出现“打开资源管理器”或“Windows 安全中心”提示？

    本页的“打开”按钮会调用 Windows 资源管理器，在上方文件夹中查找压缩包。浏览器和 Windows 可能分别确认这次操作。

    “此站点正在尝试打开 Windows 资源管理器”：如果这是你刚点击本页“打开”后出现的提示，可选择“打开”。不需要勾选“始终允许”。其中的 file:// 表示当前打开的是电脑上的本地帮助页。

    “Windows 安全中心：打开这些文件可能会对你的计算机有害”：如果它紧接着上述操作出现，可先展开“显示详细信息”，核对打开的是本页指定文件夹的资源管理器搜索；确认后选择“确定”继续。这一步只定位压缩包，不会运行其中的程序。

    如果提示内容与上述操作不符，或不想通过这些确认，请选择“取消”。也可以直接复制上方文件夹路径，粘贴到资源管理器的地址栏，再打开压缩包，无需更改系统安全设置。

  2. 将压缩包中的内容解压到这个文件夹：

    将复制的路径粘贴到解压窗口的目标位置，然后开始解压。请解压全部内容，保留压缩包自带的文件夹名称。

  3. 回到游戏继续。解压完成后，在已经显示的弹窗里选择“是，检查并打开”。

疑难解答

在网页中没有看到文件夹位置？

文件夹位置由游戏自动填写。直接双击帮助文件，或从收藏夹打开旧网页时，页面可能没有收到本次安装的位置。

请回到游戏，重新点击安装渲染器，或重新尝试“导出并打开”，让游戏重新打开帮助网页。如果位置仍为空，请复制下方反馈信息并告诉作者。

游戏无法检测到渲染器

请确定渲染器已经放到了正确的位置。第 2 步显示的文件夹里，应直接看到 CSLModernMapRenderer-版本号 文件夹，打开它应能看到 CSLModernMapRenderer.exe 和 engine 文件夹。

如果外面还多套了一层同名文件夹，请将里面带版本号的文件夹放到第 2 步的位置。然后回到游戏选择“查看帮助”，重新确认解压完成。

请等待全部文件解压完毕，不要只取出一个程序，也不要在压缩包里直接运行。更新时，请解压本次新压缩包中的全部内容。

解压时提示没有权限

请确认解压目标与第 2 步一致。如果 Windows 要求管理员许可，可按提示继续；如果仍提示“拒绝访问”，请让电脑管理员为你的账户开放该文件夹的修改权限，再重新解压。

How to manually install or update the renderer

The game could not install the renderer automatically. This may be caused by permissions or another unusual situation.

The game normally checks and installs the renderer for you. Follow these steps to install it yourself and open your map.

  1. Open the archive in this folder using File Explorer:
    OpenNo folder location shown?

    Find and open CSLModernMapRenderer.zip. Clicking Open may first show a browser or Windows confirmation. See the explanation below.

    Seeing an “Open File Explorer” or “Windows Security” prompt?

    This page's Open button asks Windows File Explorer to find the ZIP in the folder shown above. Your browser and Windows may each ask you to confirm this action.

    “This site is trying to open Windows File Explorer”: if this appears after you click Open on this page, choose Open to continue. You do not need to select Always allow. The file:// label means this help page is a local file on your computer.

    “Windows Security: Opening these files might be harmful to your computer”: if this follows the action above, expand Show details and check that it is the File Explorer search for the folder specified on this page. Once confirmed, choose OK to continue. This step only locates the archive; it does not run any program inside it.

    If the prompt does not match this action, or you prefer not to continue, choose Cancel. You can also copy the folder path above into File Explorer's address bar and open the ZIP yourself, without changing system security settings.

  2. Extract the archive's contents into this folder:

    Paste this path into the extraction window's destination field. Extract all contents and keep the folder name supplied in the ZIP.

  3. Return to the game to continue. Once extraction finishes, choose Yes, Check and Open in the dialog already waiting there.

Troubleshooting

No folder location shown on this page?

The game supplies the actual folders automatically. Opening the help file directly or using an old bookmark may omit the current installation's locations.

Return to the game and try installing the renderer or exporting and opening your map again, so the game opens a fresh help page. If the locations are still missing, copy the feedback below and tell the author.

The game cannot detect the renderer

Check that the files are in the correct place. The folder in step 2 should directly contain CSLModernMapRenderer-version. Open it to find CSLModernMapRenderer.exe and the engine folder.

If an extra enclosing folder is in the way, put the versioned folder directly in the location shown in step 2. Return to the game, choose View Help, and confirm extraction again.

Wait for every file to finish extracting. Do not extract just one program or run it from inside the ZIP. To update, extract the complete new archive.

Extraction says access is denied

Check that the destination matches step 2. If Windows asks for administrator permission, follow its prompt. If access is still denied, ask the computer's administrator to let your account modify that folder, then extract again.
